# 参考：终末地项目的封面

## 诀（李织烟）个人向 · Game of Survival

- 命令：`python3 -I $C/cover.py WFY0ApEUleo 73.1 out/封面_诀_无字.png --at 0.62,0.45`（其余参数用默认值）。
- 画面：《Beyond the Traces》里她从持炮的手臂后抬眼，额间红纹居中，炮管和手臂横贯三格。
- 颜色：侧格用她的青色发色和法术光效（110,200,196），细线用额间红纹的红（214,40,48）。
- 比较过的原型：
  - 只调色加一条短红线：设计感不够。
  - 斜切双色调：红线压到眼睛，而且双色调平板。
  - 同一画面三格：侧格去色发灰。
  - 三格加双色调侧格：定稿。
  - 换成正脸特写（WFY0ApEUleo 116.6）时，右格只剩空背景，说明主体要横跨几格。

## 开服至 1.6 主线 · Warriors

- `out/封面_我们绝不放弃.png`、`out/封面_无字.png` 是旧版脚本做的：单帧调色加暗角，带字版另加左侧标题。
- 用户之后明确要求封面无字且有设计感，所以这两张都不符合现在的标准。
