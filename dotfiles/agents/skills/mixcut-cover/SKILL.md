# 视频封面：无字，有设计感

脚本在本 skill 的 `scripts/` 目录，先 `C=<本 skill 目录>/scripts`。在项目根目录运行，用 `mixcut-pipeline` 的环境：`$S/env.sh python3 -I $C/cover.py …`（`S` 是同级的 `mixcut-pipeline/scripts`）。它读取 `src/<id>.mkv` 和 `analysis/shots/<id>.json` 里的黑边裁切。

终末地的两个实例见 [references/endfield.md](references/endfield.md)。

## 用户的标准

- **默认无字。** 不放标题、角色名、logo、水印字。标题写在投稿标题里。
- **必须有设计感。** 设计感来自版式、色彩系统和一两处克制的图形元素，不能只是把一帧调色、加暗角就交差。
- **不用界面元素。** 取景框、准星、HUD 圆环、进度条一类图形，用户在视频里明确说过"没有沉浸感"，封面同样不用。
- 不用官方名片和立绘展示卡，不把几个不同镜头拼贴在一起（左右拼接在视频里被否过）。

## 默认版式：分格

`cover.py` 的做法：

1. 一帧画面铺满 16:9，切成几条竖格。格与格之间是深色窄缝，各格上下错开几十像素，形成"同一画面被切开"的编辑感。
2. 主体（眼睛）所在的那一格保留原色，其余格压成双色调（深墨色到 `--tone`）。整张图只剩"原色主体 + 一种主题色"两套颜色。
3. 主体右侧的缝里放一条强调色细线（`--accent`）。颜色取角色的标志性细节，例如额间红纹、发带、徽记。
4. 统一收尾：阴影偏冷、高光偏暖的分离色调，高光辉光，轻暗角，细颗粒。

```sh
python3 -I $C/cover.py <src-id> <time> out/封面_xxx.png --at 0.62,0.45 [--cuts 0.28,0.72] [--tone 110,200,196] [--accent 214,40,48]
```

| 参数 | 作用 |
|---|---|
| `--at x,y` | 主体（眼睛）在源画面中的位置（0–1），落到封面水平正中、自上 45% 处 |
| `--zoom` | 在铺满的基础上再放大，默认 1.08 |
| `--cuts` | 分格位置（封面宽度的比例），两刀三格最稳；格子不要等分 |
| `--shift` | 每格上下错位（像素），默认左格上提、右格下沉 |
| `--tone` | 侧格双色调的亮部颜色，取角色或作品的主题色（发色、技能光效） |
| `--accent` | 细线颜色，取标志性的小面积颜色，要和 `--tone` 形成对比 |
| `--seam` | 放细线的缝（1 起数），0 不放 |

## 选帧

1. **人物特写，最好看见眼睛。** 封面在信息流里只有几百像素宽，远景人物会糊成一团。
2. **主体要横跨几格。** 手臂、武器、飘起的头发这类横向元素要延伸到侧格里，侧格的双色调才有内容。只有一张居中的脸时侧格是空的，版式会塌。
3. **画面干净。** 没有字幕、名片、MV 界面元素，也没有烧录的歌词。字幕常在画面下缘，要看清楚。
4. **情绪和片子一致。** 燃向片子选正在战斗或蓄势的表情，不选闭眼和背影。
5. 用 `mixcut-pipeline` 的 `peaksheet.py`、`strips.py` 找候选帧，先抽一组全分辨率帧放在一起比较，再出封面。

## 交付前检查

- 原尺寸看一遍，再缩到约 320 像素宽看一遍：主体和眼睛一眼能认出，色块关系清楚。
- 细线不能压在脸上或眼睛上。
- 侧格不能大面积是空背景；空的话换帧，或调整 `--at` 和 `--cuts`。
- 输出 1920×1080 PNG，文件名带 `封面_` 前缀放进 `out/`。

## 换一种版式时

分格不适合所有画面。需要新版式时仍按这几条来：一个原色主体，一种主题色，一处强调色，一套统一收尾；不加字，不加界面元素。先在 `/tmp` 里出两三个原型并排比较，选定后再写进 `cover.py`。
