# 学科讲解与短示例

按当前学科选读。以下自编例子用于说明应解释哪些步骤。

## 数学分析

说明研究的对象、使用方法的条件，以及关键变形为什么成立。证明题写清已知、目标和推理过程。量词、区间、收敛条件、积分次序、换元范围及雅可比因子在用到时解释，数值例子不能代替证明。

同一个字母既可能表示变量又可能表示函数；如参数化中的粗体 r 是位置向量，不能只把它说成“半径”。面对 dx、ds、dS，先说明积分对象与相应微元的含义，再做计算。只定义本题出现的符号，不预先塞入整张符号表。

**示例：从几何区域连接到积分限。**

原稿片段（自编）：“二重积分可以按先 y 后 x。区域是 x 从零到一，y 在零和 x 之间。例题算 x 加 y 的积分。换次序画图。”

可采用的精讲：

“二重积分先要确定每一次累加覆盖哪里。这里先固定一个 x，竖直截线上的 y 从 0 变化到 x；把这一小条算完，再让 x 从 0 变化到 1。因此，内层限由当前 x 决定，外层限覆盖全部截线：

\[
\iint_D(x+y)\,dA
=\int_0^1\!\int_0^x(x+y)\,dy\,dx
=\int_0^1\frac32x^2\,dx=\frac12.
\]

内层积分时 x 暂时固定，故 x 对 y 的积分是 xy。若换成先对 x 积分，就改看水平截线：在固定的 y 处，x 从 y 到 1，而 y 的总范围是 0 到 1。所以是

\[
\int_0^1\!\int_y^1(x+y)\,dx\,dy.
\]

换积分次序改变的是切分方式，区域本身不变；不能只把 dx、dy 互换而保留原积分限。”

这里用截线说明积分限，再进行计算。若图能帮助辨认区域，补上准确的区域示意。

## 大学物理与电磁学

先说明物理模型，再列式计算。区分标量与向量、场与通量、受力方向与大小、局部量与总量。求场题解释对称性、为何选择这个面或回路、包围多少电荷或电流，以及为什么分段。

**示例：高斯定律如何变成求场公式。**

“电通量描述电场穿过曲面的情况；高斯定律把闭合曲面的总通量与内部电荷联系起来。要进一步求某点的场强，还需要知道电场在高斯面上怎样分布。

对半径 R、体电荷密度 ρ 的无限长均匀带电实心圆柱，取半径 r、长度 l 的同轴圆柱面。对称性使场沿径向，侧面上场强大小相同；两端面的法向沿轴向，与电场垂直，因此端面通量为零。于是

\[
E_r\,2\pi rl=\frac{Q_{\text{内}}}{\varepsilon_0}.
\]

这里 E_r 是沿径向向外取正的分量。r<R 时只包围半径 r 内的电荷，Q内=ρπr²l；r>R 时包围整段带电柱，Q内=ρπR²l。因此

\[
\boldsymbol E(r)=
\begin{cases}
\dfrac{\rho r}{2\varepsilon_0}\boldsymbol e_r,&0<r\le R,\\[4pt]
\dfrac{\rho R^2}{2\varepsilon_0r}\boldsymbol e_r,&r>R.
\end{cases}
\qquad \boldsymbol E(0)=\boldsymbol0.
\]

两式在 r=R 相接；ρ 为正时向外，为负时向内。这里能提出 E_r，靠的是所选面的对称性，而不是高斯定律自动保证它处处相等。若只知道总通量为零，一般不能据此判断各点电场为零。”

引向电势时说明新的问题：场强直接描述单位电荷的受力，电势则用单位电荷的势能描述位置差异；不要只说“接下来学习电势”。

## 物理实验

说明测量什么、怎样从测量值得到目标量，以及仪器和模型怎样影响结果。区分原始观测、零点修正、中间计算、最终结果与不确定度。标清单位、仪器分辨力和误差传播所需条件。缺少测量信息时，指出还需要哪些数据。

优先用脚本中的数据处理实例或判断题，解释为什么修正、拟合，以及怎样保留有效数字。用户需要数据演示时可使用明确标注的模拟数据，不能用它代替实测记录。

## 工程制图

先说明空间形体、投影关系或剖切目的，再落实到读图和作图步骤。区分可见轮廓、不可见结构、剖切位置与剖面线；教材或标准规定的画法与直观解释分别说清。

图纸缺失时指出缺少哪张视图或哪个尺寸，继续讲能确定的规则。未提供的结构、线型或剖切结果不能猜补。需要现行制图标准时查证适用版本。

## 英语及以阅读、论述为主的课程

将“例题”替换为教材任务、句子分析、翻译或简答示范。说明题目要求与文本依据，呈现从依据到答案的组织过程。原文、译文和辅助例句区分清楚；根据题目需要提炼词汇、句式和论证关系，不逐词铺满笔记。

其他工科课程按实际任务选例，讲清建模条件和结果含义。
