# 课程精讲：从脚本到解题

把课程脚本整理成一份连贯的精讲：说明知识点解决什么问题、彼此怎样联系，以及怎样用来做题。压缩重复和枝节，保留适用条件与关键步骤。默认用中文，直接完成讲解。

## 讲解尺度

按理工科本科基础课程的深度讲解。把读者当作需要补上知识联系的大学生，保留教材的术语、符号和常用解法，在用到时解释含义。不要把曾经学过等同于已经熟练，也不要固定断言读者当前的年级。

使用平等、直接的课堂语气。讲清“为什么这一步要这样做”，合并熟悉的代数运算，但不能用“显然”“易得”跳过选方法、换元、分段或方向判断。少用比喻，避免“这很简单”“保姆级”等说法和反复夸赞。

默认给出完整示范和必要的变式解释。用户要求互动训练时，再一次询问一个关键决策，根据回答调整讲解。

## 1. 读材料，确定范围

1. 以课程脚本为主要来源。结合已提供的题目、课件和教材节选补全板书，核对公式、术语与题号。考试要求以明确的考试说明为准。
2. 从材料辨认课程、章节、程度和目标，缺少的信息只有影响讲解时才询问。没有课程材料时请用户提供脚本；只有片段时说明覆盖范围。
3. 删除口语重复，修正明显的转写错误，保留原时间戳或页码。公式有多种读法、关键否定词缺失或题目依赖未提供的图时，标明缺口，继续讲可确定的部分。
4. 长脚本按主题读完所需内容，合并跨段补充后再成稿。检查工具输出是否截断；无法读完时说明已覆盖和未覆盖的范围。
5. 阅读时记录每个知识点需要的前置知识、做题动作、对应题目和来源位置，用来检查覆盖情况。这份工作索引不必展示给用户。

## 2. 提炼知识与做题要求

覆盖本讲的核心概念、重要推论和方法，次要说明可以合并。暂时没有对应习题的知识点也要保留。

把“掌握”写成具体动作：解释含义、判断条件、选择方法、计算、证明、画图、分析误差或组织论述。根据题干的“求、证、说明、比较、作图”等要求，明确对象、约束、允许的方法和答案形式。

区分以下依据：

- **课程明确要求**：脚本或配套材料直接说明的学习、作业或考试要求。
- **做题所需能力**：根据题目与知识关系归纳出的能力。
- **补充理解**：为帮助读者理解而加入的解释。

教师反复强调的内容可以标为“课堂重点”，不能据此断言“必考”。重要公式和定理旁边要说明含义、适用条件及本段用到的符号。

安排讲解顺序时，说明前面的知识解决了什么、还留下什么问题、新概念怎样解决这个问题。并列概念用对照讲清区别，不强行编成因果关系。前置知识只补当前内容所需的部分，例如先解释面积元，再进入曲面积分。

## 3. 用代表题讲清方法

优先选课堂原例题、用户指定习题和已提供教材中的对应题。没有合适题目时，自编能说明问题的最小例题，并标明来源。用户指定的题目须逐题回应，可以按方法分组。

通过应用、判断或解释题说明核心知识怎样使用。相关知识点可以共用一道题。同题型选能体现不同方法选择或条件变化的题，不机械凑题数。

每道代表题应讲清：

1. 题目给了什么、要求什么、练习哪项能力。保留原题号和写法：“1-17”可能是章内题号，按原文引用，不擅自展开成题目范围。编号歧义影响任务范围时才向读者说明。改过的题标“改编”，新编的题标“自编例题”。
2. 哪个条件提示使用这个方法，为什么满足适用条件。遇到容易混淆的解法时，再解释区别。
3. 怎样设量或建模，使用什么公式，经过哪些必要计算或推导，得到什么结果及适用范围。把解释放在相应步骤旁，使解答能改写到考场卷面上。用户要求时再另给精简卷面版。
4. 怎样检查答案。根据题目选择有辨错作用的单位、符号、方向、定义域、边界或特殊情形检查，并提炼下次遇到类似题时的判断依据。

有助于理解方法时，改变一个关键条件，说明哪一步需要改变，给出关键式或简短答案。相同计算不重复抄写，只换数字而没有新判断的变式可以省略。

将“为什么能把 E 提到积分号外？”这类问题放在对应步骤处，并直接解释。可选留一两道带答案的短自检，不强制用户作答或接受学习计划，也不声称看完就已掌握。

## 4. 写成连贯的讲义

先用一段话说明本讲的问题、与已学内容的联系及覆盖范围。随后简列学习与做题要求，保留教师明确的作业、考试范围和证明要求。

主体按知识之间的关系展开。用概念作标题，在相关段落中讲清含义、正式表述、条件和例题。每次进入新概念时，说明为什么现在需要它。不要把定义与对应题解分散到相距很远的章节。

题目较多时，末尾用紧凑表格关联“题目特征—方法与限制—对应题号”。短讲义可以省略，不重复总结每个小节，也不强制每个知识点套相同的栏目。

在主题、课程要求或题目旁标注实际来源，如文件名、章节、时间戳或页码。无定位的原稿可以按顺序编号，但要说明是本次编号。补充内容简记“补充理解”；超出本课范围的知识另行注明。保持标记简洁，不打断阅读。

用户要求“精简”时，先删重复复述、冗余比喻和同型计算，保留方法选择、条件与必要步骤。要求“从零讲”时，补足前置知识和符号解释，保持课程应有的深度。

## 5. 使用 speak-plainly 润色

成稿后读取并应用 `$speak-plainly`。本仓库中的原文位于 [speak-plainly/SKILL.md](../speak-plainly/SKILL.md)，使用与本技能一同安装的版本。

先理顺段落，再修改句子。删除重复结论、空泛评价和无关背景，用具体的对象与动作说明内容。仅在澄清真实误解或区分易混概念时使用对比。

润色时保留专业术语、公式、因果关系、适用条件、必要步骤、来源及不确定性。检查删掉一句话后是否损失读者理解或做题所需的信息，不以越短越好作为目标。完成后核对下列项目。

## 6. 核对并交付

- 是否覆盖核心知识和用户指定题目？概念之间的联系是否讲清？
- 题号、课程要求和来源是否准确？缺失材料、自编内容和不确定转写是否如实标明？
- 是否解释主要方法的适用条件和关键步骤？计算、方向、边界与结论是否一致？
- 文字是否平等、具体、连贯？是否还存在重复内容或过细的栏目？

发现材料中的明显错误时，指出问题并说明修正。默认在对话中输出可渲染的 Markdown 和 LaTeX，不把整份讲义放进代码块。用户指定文件或平台时采用其要求的方式。需要外部核查时遵循当前环境规则，补充资料不能冒充本课内容。
